# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Do not open a public GitHub issue.

- Use GitHub's private vulnerability reporting: open the repository's **Security** tab and
  choose **Report a vulnerability**.
- Or email **sergeipwallace@gmail.com**.

Include a description of the issue, steps to reproduce it, affected versions or
configuration, and the potential impact. We will acknowledge the report within
48 hours and aim to provide a remediation timeline after confirmation.

## Supported versions

Only the latest release and the `main` branch receive security fixes.
